# SmartFactory-Vision

SmartFactory implementation using JPyRust for native AI integration.

## Features
- Real-time webcam streaming with AI detection.
- JPyRust integration for high-performance Python-Java bridging.
- Dynamic Shared Memory for secure and fast data transfer.

## Tech Stack
- Java 17 (Spring Boot)
- Python (Ultralytics YOLOv8)
- JPyRust (Native Bridge)
- WebSocket for streaming
